# Memory: ui/schedule-page
Updated: now

A interface da Agenda (Schedule) utiliza um layout responsivo com três modos de visualização:
- **Dia**: Grid de atividades por hora com itens de negociações do Pipeline integrados
- **Semana**: Grid semanal 7x14 horas com itens de negociações do Pipeline integrados
- **Calendário**: Calendário compacto centralizado com badges de contagem de eventos

Os itens de negociações (atividades, tarefas e previsão de fechamento do Pipeline) aparecem diretamente nos grids com ícone de maleta e cor primária para diferenciá-los de atividades regulares.

Os cards de visita exibem o status 'Cliente Informado' quando lead_confirmed é true.
